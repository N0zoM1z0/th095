# Kaze no Gogai: Sakuya Grand Geometry / Hard v5

This guide covers the unfinished Sakuya v5 sampler. See the
[project overview](README.md) and [current status](STATUS.md).

All eight extra-issue slots feature Sakuya for comparing harder, multi-phrase
spell designs. This revision adds charged mass salvos, full-size knives, speed
layers, multi-stage turning, native ricochets and several rotating geometry
families. Earlier standalone issues remain separate.

Open PREVIEW.html in this standalone folder for actual screenshots and a rotary
sequence. It shows attack phases without starting the game.

Run launch-gogai.bat, choose Game Start, then press Left once from LEVEL 1 to
select Extra Issue 1 (group 12). All eight scenes are immediately available.

Arrow keys move. Shift focuses. Shift+Z charges quickly. When fully charged,
release Shift, hold Z to aim, then release Z to photograph. Escape pauses in
ordinary time. The native player/camera input also stops during actual stopped
time. Preparation markers do not yet count as photo targets.

Gathering knives around Sakuya announce a mass release. Blue/purple/white layers
often travel at different speeds, so the fast shell can overtake the slow one.
Read the new headings after a stop, and allow for blades returning from side
walls or the ceiling. The corridor is much narrower, shifts between salvos and
is crossed by other attack phrases; it is not a permanent safe column.

For camera evasion, bait the dodge and reframe during its cooldown. Rotating
streams have moving emitters and several spiral layers. Decorative gathering
knives and pose trails are visual effects, never extra photographic subjects.

For no-death practice, run run-no-death-test.bat with its PowerShell helper
beside it. It disables collision death only in its newly started game process;
it never changes the executable on disk. The timer still runs. Close that
process and use launch-gogai.bat for ordinary play. Replays containing collisions
require no-death playback. The helper accepts only this verified v5 executable.

This folder owns fresh scores, photographs and replays. Do not mix old prototype
saves/replays into it. Manual BAT launches retain ordinary graphics, music and
sound. See VALIDATION.md for actual test coverage and remaining limits, and
GRAND_GEOMETRY.md for the compositions and original-asset pose limitations.
