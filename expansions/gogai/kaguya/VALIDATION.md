## Manual launcher and practical limits

The PowerShell helper is pinned to the SHA-256 above, death RVA 0x33D50 and
18-byte entry 558bec83ec20894de08b45e0c70002000000. Static PE checks and the
Wine probe agree on this identity; the runtime patch is read back. The disk
executable remains unchanged. The existing Windows helper body is retained
with a Kaguya pin and corrected repository fallback; no native Windows game
launch is performed during this revision.

Delivery includes fresh save directories and normal windowed graphics, music
and effects. Private silent configuration, diagnostic scores and test replays
are excluded. The deployed folder is not launched during testing.

Artistic preference, hardware performance and complete ordinary-mode balance
remain for human playtesting. Native Windows close stability remains unverified
after an older issue's fault. An earlier Sakuya candidate's canceled-shot stall
has no established general fix; it was not observed in these completed tests.
Private decoder warnings on some original reference scripts are not used as
reconstruction, ABI or compiler evidence. Read-only TH08 design references are
documented in README.md; no TH08 code, layouts or byte-match claims are imported.
