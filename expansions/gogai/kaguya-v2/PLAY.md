# Kaguya: Living Treasures / Hard v2

Open PREVIEW.html to inspect how each pattern grows through actual native
screenshots. It includes a separate formation sequence for every card.

Double-click launch-gogai.bat. Choose Game Start, then press Left once from
LEVEL 1 to select Extra Issue 1 (group 12). All eight scenes are available.

Arrow keys move; Shift focuses. Shift+Z charges quickly. At full charge, release
Shift and hold Z to aim; release Z to photograph Kaguya. Escape pauses.
Scenes 1-5 need six valid photographs, scenes 6-7 need seven, and scene 8 needs
eight. Ornaments near the hands are not extra photographic subjects.

Read the gathering pose and the first threads of a phrase. Their future curves
and speed differences develop the larger figure as they travel. Fast stars or
jewel heads can overtake slower threads; some dragon heads return from walls.
Laser strokes extend one after another, with a thin startup warning before
collision growth. Native photography clears bullets and cuts laser geometry.

Use run-no-death-test.bat for practice. Keep the PowerShell helper beside it.
It verifies this artifact's SHA-256 and death-function prologue before patching
one byte in its newly started process, then reads the byte back. It changes no
file on disk. The timer remains active. Replays containing collisions need
no-death playback. Close the process and use launch-gogai.bat for ordinary play.

Manual launches retain normal windowed graphics, music and effects. This folder
has independent fresh scores, photographs and replays. Do not mix v1 or Sakuya
saves into it. Earlier standalone folders and source tags remain preserved.

See README.md for the compositions and concrete TH08 study, SPELL_LIBRARY.md
for preserved designs, and VALIDATION.md for this artifact's actual coverage.
Artistic preference and ordinary-mode human balance remain for playtesting.
